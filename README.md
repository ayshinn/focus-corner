# focus-corner

Personal aesthetic workspace dashboard — pomodoro, todo, ambient backdrop, music control, optional Spotify and Google Calendar integrations. Static site, hosted on GitHub Pages at https://ayshinn.github.io/focus-corner/.

See [`productivity_site_spec.md`](./productivity_site_spec.md) for the full design spec and [`implementation_steps.md`](./implementation_steps.md) for the build plan. Progress is tracked in [`todo.md`](./todo.md).
